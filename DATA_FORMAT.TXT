INPUT DATA FORMATS FOR 2D IMAGES

The programs process binary 2D and 3D images.
There are only two colors: 1 = foreground, 0 = background.

2D images are accepted in the standard image formats (png,jpg).
If the image is not binary, it is converted to binary by applying
a threshold.

A raw binary data format is also accepted. The file is binary,
the first four bytes are the two image dimensions (on 2 bytes each,
in little-endian byte order). Next, we have the colors of the pixels,
on one byte each.

3D images are accepted in (binary or ascii) vtk format with
DATASET STRUCTURED_POINTS and scalars associated with cells.

A raw binary data format is also accepted. The file is binary,
the first six bytes are the three image dimensions (on 2 bytes each,
in little-endian byte order). Next, we have the colors of the voxels,
on one byte each.
