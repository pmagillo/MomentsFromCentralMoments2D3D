CONTEXT, PURPOSE, REFERENCES

The context is moment computation of binary 2D and 3D images.
The purpose of this prototype Python code is experimenting an
optimization for decomposition-based algorithm.

A decompositon-based algorithm has three stages:
  A) decompose the image foreground into square or rectangular
     elements
  B) precomputation of useful information
  c) compute the moments of the elements of the decomposition
     (their sums are the moments of the image)
The optimization precomputes central moments in stage B and
uses them to simplify stage C.

Two schemes of decomposition are used:
 1) quadtree/octree, original algorithm described in:
   C.-H. Wu, S.-J. Horng, P.-Z. Lee,
   A new computation of shape moments via quadtree decomposition,
   Pattern Recognition, 34(7), 1319-1330, 2001.
 2) block decomposition, original algorithm described in:
   I.M. Spiliotis, B.G. Mertzios,
   Real-time computation of two-dimensional moments on binary
   images using image block representation,
   IEEE Trans. Image Processing, 7(11), 1609-1615, 1998.
