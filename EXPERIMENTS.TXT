EXPERIMENTS


INPUT DATA
Experiments are performed on two data sets:

1) 2D binary inages obtained by discretizing vector graphics, respresenting variants of the drawn number "50".
Each drawing was discretized into a 2D image with side length equal to 512,1024,2048 and 4096
Inputs are in folder: DATA_2D

2) 3D binary images obtained by discretizing 3D shapes from the repository that was available
at  http://visionair.ge.imati.cnr.it/ (downloaded in 2022, the address is no longer working).
Each shape (given as closed triangle mesh) was discretized into a 3D image with side length equal to 128,256,512 and 1024
Input are in folder: DATA_3D

Experiments were performed to measure the execution time of the various stages of moment computation, with the two different algorithms, with our without precomputation of central moments.

Measures were take by exploiting the profiling utilities:
   python3 -m cProfile <pythonsource.py> <commandlineparameters>
   

HOW TO USE THE TEST PROGRAMS
There are four test scripts:
  testTree2D.py   textBlocks2D.py
  testTree3D.py   textBlocks3D.py

Tree or Block refer to the type of image decomposition:
quadtree/octree or block decomposition

2D or 3D refer to the size of the images

WHAT IS EXPECTED ON THE COMMAND-LINE
The source run without arguments prints instructions.

python3 source.py <stages> <how> <input> <times>

<stages> defines what to perform on the <input>,
we may perform all three stages of a decomposition based
algorithm for moment computation (A= building the decomposition,
B=preprocessing, C=computation), or just stage A, or just B+C

<how> has meaning only for stages B,C and defines how
to do it, in original version or in optimized version

<input> depends on the stage, for A it is an image, for
B+C it is an already built decomposition.

Parameters <stages> for all scripts:
ABC = perform all stages, input is an image, output is moments
A   = perform just stage A (decompose the object), input is an image,
      output is decomposition
BC  = perform just stages BC (preprocessing and moment computation,
      input is the decomposition, output is moments

Parameters <how>:
old    = original version of moment computation
new    = optimized version of moment computation
newraw = raw optimized version (only for block decomposition and on
         2D images), tentative version bringing no speed up

Parameters <stages> only for block decomposition:
ABonceC = perform all stages for many images, with preprocessing
          executed once, input is a text file containing the maximum
          image side and the list of images (one on each line)
BonceC  = perform just stages BC for many block decompositions,
          with preprocessing executed once, input is a text file 
          containing the maximum image side and the list of block
          decompositions

EXAMPLES OF USE FOR 2D IMAGES

Build quadtree and compute moments in all possible ways:
  python3 testTree2D.py ABC old ./DATA_2D/draw00_512.png
  python3 testTree2D.py ABC new ./DATA_2D/draw00_512.png

Build quadtree and write it:
  python3 testTree2D.py A anything ./DATA_2D/draw00_512.png
(the file draw00_512_tree2D.txt is generated)

Load quadtree and compute moments in all possible ways:
  python3 testTree2D.py BC old draw00_512_tree2D.txt
  python3 testTree2D.py BC new draw00_512_tree2D.txt

Build block decomposition and compute moments in all possible ways:
  python3 testBlocks2D.py ABC old ./DATA_2D/draw00_512.png
  python3 testBlocks2D.py ABC newraw ./DATA_2D/draw00_512.png
  python3 testBlocks2D.py ABC new ./DATA_2D/draw00_512.png

Build block decomposition and write it:
  python3 testBlocks2D.py A anything ./DATA_2D/draw00_512.png
(the file draw00_512_block2D.txt is generated)

Load block decomposition and compute moments in all possible ways:
  python3 testBlocks2D.py BC old draw00_512_block2D.txt
  python3 testBlocks2D.py BC newraw draw00_512_block2D.txt
  python3 testBlocks2D.py BC new draw00_512_block2D.txt

Build block decomposition and compute moments for many
images with amortized preprocessing time:
  python3 testBlocks2D.py ABonceC old listof2Dimages.txt
  python3 testBlocks2D.py ABonceC new listof2Dimages.txt

Load block decomposition and compute moments for many
decompositions with amortized preprocessing time:
  python3 testBlocks2D.py BonceC old listof2Ddecomp.txt
  python3 testBlocks2D.py BonceC new listof2Ddecomp.txt
